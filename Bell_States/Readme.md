# Bell States Project

This project demonstrates the creation and simulation of all four Bell States using Qiskit and AerSimulator.

## Bell States Implemented

1. Phi Plus (Φ⁺)
2. Phi Minus (Φ⁻)
3. Psi Plus (Ψ⁺)
4. Psi Minus (Ψ⁻)

## Technologies Used

* Python
* Qiskit
* AerSimulator

## Project Objective

To understand quantum entanglement and Bell States by creating, simulating, and measuring all four Bell States.
